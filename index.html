Indeks · enam seri

Belajar Web3, dari fondasi pemrograman sampai rilis testnet.

Enam docs web statis berbahasa Indonesia. Mulai dari JavaScript, TypeScript, async, API, BigInt, dan Git. Lanjut ke cara kerja blockchain, menulis kontrak Solidity, menguji dan men-deploy dengan Foundry, membangun frontend Next.js yang terhubung ke wallet, lalu membawa dApp ke Sepolia dan memverifikasinya. Setiap seri punya lab interaktif dan uji kompetensi.

Cara membaca

Pilih satu seri, lalu ikuti bab secara berurutan. Progres per bab dan skor uji kompetensi disimpan di localStorage browser ini, jadi bisa dilanjutkan kapan saja di perangkat yang sama.

Semua lab berjalan di browser tanpa server, tanpa akun, dan tanpa wallet yang terhubung. Angka di dalam lab adalah ilustrasi, bukan data jaringan sungguhan.

Menjalankan lokal

Buka index.html langsung di browser, atau jalankan server statis dari folder ini:

  • python -m http.server 8765
  • lalu buka http://127.0.0.1:8765/

Versi online tersedia lewat GitHub Pages di alamat repo ini.
