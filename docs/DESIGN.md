# Arah desain: Buku Besar

Reading this as: a technical field guide for Indonesian beginners learning blockchain, in a ledger-inspired editorial style, dial ENERGY 2 / RHYTHM 2 / MOTION 1.

## Subjek dan audiens

Pembelajar tahap 2 minggu 3 yang sudah paham web dasar, belum menulis smart contract, dan butuh satu tempat untuk memahami istilah, alur, dan risiko. Docs ini juga menjadi jembatan ke proyek wallet kecil yang sudah ada di folder induk.

## Token

- Warna: kertas `#F4F5F0`, tinta `#18201B`, hijau ledger `#145C43`, rust peringatan `#9C3D2E`, abu garis `#D6DAD0`.
- Tema gelap: kertas `#101512`, tinta `#E7E9E1`, hijau `#6FD3A6`, rust `#E8917F`.
- Tipografi: Newsreader untuk judul bab (membaca seperti catatan lapangan, bukan dashboard), Public Sans untuk badan (jelas di layar), IBM Plex Mono untuk hash, alamat, dan kode (data harus terlihat sebagai data).
- Bentuk: radius 3px sampai 6px, garis tipis, tanpa bayangan mengambang.
- Irama: prosa sempit untuk membaca, instrumen lab lebih lebar, tabel dan diagram memutus irama.

## Prinsip

1. Setiap hiasan harus mengangkut informasi. Garis buku besar hanya muncul di pembuka dan pemisah bab karena menandai urutan, bukan tekstur.
2. Angka yang ditampilkan berasal dari perhitungan nyata di browser atau diberi label contoh. Tidak ada statistik karangan.
3. Lab adalah tempat mencoba, bukan tangkapan layar. Semua kontrol punya perilaku.
4. Progres adalah alat navigasi. Tanda selesai disimpan lokal dan muncul di sidebar.
5. Docs harus enak dibaca lama: kontras tinggi, lebar baris di bawah 75 karakter, fokus keyboard terlihat.

## Larangan yang dipatuhi

Tanpa gradien dekoratif, glow, glassmorphism, grid latar, kartu seragam, ikon sparkle, em dash, atau klaim palsu. Gerak hanya untuk umpan balik lab dan buka tutup navigasi, sesuai dial MOTION 1.

## Alasan keputusan besar

- Palet hijau dan kertas: buku besar dan verifikasi, bukan crypto-neon.
- Newsreader: memberi jarak dari estetika dashboard developer dan menandai ini bahan belajar.
- Sidebar dengan progres: docs panjang butuh peta dan rasa maju.
- Lab bergaris tegas: memisahkan "membaca" dari "mencoba", sehingga kontrol terasa seperti alat.
- Tanpa animasi masuk: pembaca docs datang untuk teks, bukan pertunjukan.
